## Recommendation

> **Quote this project at P27,500 once-off, excluding VAT if applicable.**

For negotiation, a reasonable working range is **P24,000–P32,000**, excluding VAT if applicable. I would not discount below **P22,000** unless the buyer receives a clearly reduced scope or accepts the site without the post-launch handover and support described below.

This is not a basic template site. The completed work includes a branded responsive e-commerce storefront, cart and checkout experience, a protected separate admin application, Supabase-backed customer and order persistence, R2 multi-image media storage, Cloudflare Workers deployment, operational monitoring, order-receipt logic, security hardening, mobile fixes, automated regression tests, and production acceptance work.

## Recommended commercial terms

Use a milestone structure rather than asking for the full amount at the beginning. A fair approach for this project is **40% on acceptance of the proposal (P11,000), 40% on staging/client review (P11,000), and 20% on final handover or go-live (P5,500)**. Keep scope additions—such as DPO online payment, product data entry beyond the agreed number, professional photography, paid advertising, or extensive copywriting—in a written change request.

The quote should state that the buyer receives the agreed source code and deployment handover after final payment. It should also distinguish one-off development from recurring third-party charges, including domain registration, email delivery, payment-processing charges, premium software, and marketing spend.
